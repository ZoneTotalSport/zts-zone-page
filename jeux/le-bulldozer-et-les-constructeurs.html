Le bulldozer et les constructeurs

Les bulldozers renversent les cônes, les constructeurs les relèvent.

⏱️ 10 minutes (manches de 2-3 min)
🎒 Matériel▶️ Déroulement🔄 Variantes

▶️ Déroulement

  1. Ce jeu se joue avec 12 à 30 joueurs divisés en DEUX ÉQUIPES. L'enseignant disperse 20-30 CÔNES sur le terrain : la MOITIÉ debout, l'autre moitié renversée (couchée sur le côté).
  2. ÉQUIPE CONSTRUCTEURS (dossards bleus) : leur mission est de RELEVER tous les cônes renversés pour les remettre DEBOUT.
  3. ÉQUIPE BULLDOZERS (dossards rouges) : leur mission est de RENVERSER tous les cônes debout pour les mettre COUCHÉS.
  4. Au coup de sifflet, les deux équipes agissent SIMULTANÉMENT. Les constructeurs relèvent, les bulldozers renversent. C'est une course PERMANENTE !
  5. Après un temps fixe (2-3 minutes), l'enseignant siffle. TOUT LE MONDE S'ARRÊTE immédiatement. L'enseignant compte : plus de cônes debout = constructeurs gagnent. Plus de cônes renversés = bulldozers gagnent.
  6. Les joueurs ne touchent QU'UN cône à la fois : ils ne peuvent pas en relever/renverser deux simultanément. Après avoir touché un cône, ils cherchent le PROCHAIN cône à modifier.
  7. Les joueurs ne PROTÈGENT PAS les cônes (ils ne restent pas à côté d'un cône pour empêcher l'adversaire de le toucher). Action constante, pas de gardiennage !
  8. Il est INTERDIT de : lancer les cônes, les cacher, les retirer du terrain, bloquer physiquement un adversaire, ou toucher plus d'un cône à la fois.
  9. ⚠️ SÉCURITÉ : Les joueurs se penchent pour toucher les cônes — attention aux collisions de têtes ! L'enseignant rappelle de regarder autour de soi avant de se pencher. Pas de course effrénée tête baissée.
  10. Après chaque manche, les équipes ÉCHANGENT les rôles. Les constructeurs deviennent bulldozers et vice-versa.
  11. Durée : 10 minutes (3-4 manches de 2-3 minutes). L'enseignant ajuste le nombre de cônes selon la taille du groupe.
  12. Ce jeu développe l'endurance, la vitesse, l'observation et la prise de décision rapide.

🎒 Matériel

  • 20-30 cônes

📐 Disposition

Cônes debout dispersés. Deux équipes.

🔄 Variantes

  • Cônes de couleurs avec ordre pour les constructeurs : les cônes sont de 3 couleurs. Les constructeurs doivent relever les cônes dans un ORDRE spécifique (d'abord rouges, puis bleus, puis jaunes). Un cône bleu relevé avant que tous les rouges soient debout ne compte pas. Les bulldozers n'ont pas cette contrainte. Ajoute de la stratégie.
  • Super cônes valant 3 points : 4-5 GRANDS cônes (ou cônes d'une couleur spéciale) valent 3 POINTS au lieu de 1. Les équipes doivent décider : se concentrer sur les super cônes (valeur élevée mais rares) ou sur les petits cônes (valeur faible mais nombreux) ? Ajoute un choix stratégique.
  • Un inspecteur qui peut geler un joueur : l'enseignant désigne 1-2 « inspecteurs » (joueurs neutres avec dossards jaunes). L'inspecteur peut GELER un joueur de n'importe quelle équipe en le touchant. Le joueur gelé reste immobile 10 secondes. L'inspecteur ajoute un élément d'imprévisibilité.
  • Bulldozers à une main : les bulldozers ne peuvent renverser les cônes qu'avec UNE SEULE MAIN (la non-dominante). Les constructeurs utilisent les deux mains normalement. Cela équilibre le jeu car renverser est plus facile que construire. L'enseignant ajuste le handicap selon les résultats.
