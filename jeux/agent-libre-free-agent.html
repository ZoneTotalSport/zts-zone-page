Agent libre (free agent)

Match 3 vs 3 où le 7e joueur (l'agent libre) joue TOUJOURS pour l'équipe qui a le ballon en attaque — change selon possession.

⏱️ Durée : 15-20 minutes

🎒 Matériel

  • 1 BALLON par match
  • 2 BUTS (de soccer ou cônes)
  • Dossards 2 couleurs (l'agent libre porte un 3e couleur ou aucun)

📐 Disposition

Match 3 vs 3 + 1 AGENT LIBRE (qui joue en attaque pour qui possède le ballon). 7 joueurs total. 2 buts.

▶️ Déroulement

  1. 7 joueurs : 3 vs 3 + 1 agent libre. 2 buts.
  2. L'agent libre PORTE un dossard différent (ou aucun). Il joue TOUJOURS POUR l'équipe qui A le ballon.
  3. Quand A POSSESSION CHANGE → l'agent libre RECHANGE D'ÉQUIPE instantanément. Il devient attaquant pour la nouvelle équipe.
  4. L'agent libre NE FAIT PAS DÉFENSE jamais. Il est purement OFFENSIF.
  5. Match en cours = comme un mini-soccer. But = 1 point.
  6. ROTATION : agent libre change toutes les 2-3 min.
  7. Question fréquente : « Comment savoir quand changer ? » → Quand un joueur de ton équipe a le ballon = tu attaques pour eux. Quand l'autre équipe vole = tu changes.
  8. Question fréquente : « Et si je suis confus sur le ballon ? » → Tu cours vers le ballon — tu seras toujours bien placé.
  9. Question fréquente : « L'agent libre peut-il marquer ? » → OUI. C'est même son rôle (renforcer l'attaque).
  10. ⚠️ SÉCURITÉ : pas de tackling. Espace dégagé. But contrôlé.

🔄 Variantes

  • Sans buts (5 passes = 1 pt) : versions sans tir.
  • 2 agents libres (1 par équipe en alternance) : plus complexe.
  • Plus de joueurs (5 vs 5 + 1) : pour grand groupe.
  • Mode silence : pas de communication parlée.
