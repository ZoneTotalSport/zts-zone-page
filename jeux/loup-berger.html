Loup berger

Développer le sens des responsabilités (rôle de berger); travailler la coopération et la protection; favoriser l'endurance.

🎓 Niveau : Primaire 1 → Primaire 6 (6-12 ans)👥 Joueurs : 8–30⏱️ Durée : 10-15 minutes📍 Espace : Gymnase / Extérieur🔥 Intensité : Élevé

🎒 Matériel

  • Dossards (loup, berger)
  • Plots (parc à moutons)
  • Cerceaux (optionnel)

📐 Disposition

Délimiter une zone de 'parc' avec des plots. Désigner un loup et un berger.

▶️ Déroulement

  1. Les moutons errent dans le gymnase. Le loup tente de les toucher. Le berger les escorte en sécurité vers le parc. Si un mouton est touché hors du parc, il devient loup. Le berger peut bloquer le chemin du loup (interposition). Le jeu se termine quand tous sont en sécurité ou tous convertis en loups.

🔄 Variantes

  • Berger double
  • Berger aveugle
  • Troupeaux multiples

🧑‍🏫 Rôle de l'enseignant

L'enseignant désigne le berger et le loup. Il explique que le berger protège son troupeau (les agneaux en file derrière lui). Il gère la longueur de la file et la sécurité. Il encourage les changements de rôles fréquents.

🧘 Retour au calme

La file d'agneaux marche lentement en serpentant. Le loup rejoint la file. Tout le monde marche ensemble en cercle de plus en plus lentement. Assis, respirations.

💬 Questions de réflexion

  • Comment le berger peut-il protéger efficacement le dernier agneau?
  • Que se passe-t-il quand la file travaille ensemble vs quand chacun fait sa chose?
  • Quel rôle as-tu préféré : berger, agneau ou loup?

⚠️ Erreurs fréquentes

  • La file se brise constamment : pratiquer le suivi en file avant d'ajouter le loup.
  • Le berger pousse le loup : pas de contact, le berger bloque par le positionnement.
  • Le dernier agneau se fait toucher trop facilement : les agneaux doivent se balancer en file comme un serpent.
  • Le loup abandonne : changer de loup toutes les 2 minutes.

📖 Origine

Europe (France / tradition rurale)
