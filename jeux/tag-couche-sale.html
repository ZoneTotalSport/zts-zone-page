Tag couche sale

Développer la course, l'esquive et l'entraide dans un jeu de tag avec libération par passage sous les jambes

🎓 Niveau : Primaire (1er-2e cycle)👥 Joueurs : 10–30⏱️ Durée : 10-15 minutes📍 Espace : Gymnase ou terrain extérieur🔥 Intensité : Élevé

🎒 Matériel

  • Dossards (2-3)
  • Cônes
  • Sifflet

📐 Disposition

Terrain délimité par des cônes. 2-3 chasseurs avec dossards.

▶️ Déroulement

  1. Choisir 2-3 chasseurs avec dossards. Les autres joueurs se dispersent.
  2. Au signal, les chasseurs poursuivent les joueurs libres.
  3. Quand un joueur est tagué, il se GÈLE sur place et écarte les jambes comme une arche.
  4. Le joueur gelé ne peut pas bouger tant qu'il n'est pas libéré.
  5. Pour LIBÉRER un joueur gelé, un ami doit ramper sous ses jambes (comme changer une couche!).
  6. Le joueur libéré peut immédiatement repartir en courant.
  7. Les chasseurs ne peuvent PAS taguer quelqu'un qui est en train de ramper pour libérer.
  8. Changer les chasseurs toutes les 2 minutes pour garder le rythme.
  9. Le but est que les chasseurs gèlent TOUT LE MONDE en même temps — si tous sont gelés, les chasseurs gagnent!
  10. Après 2-3 rondes, discuter des stratégies : comment se protéger mutuellement?

🔄 Variantes

  • Couche propre
  • Couche contagieuse
  • Couche royale

🧑‍🏫 Rôle de l'enseignant

Expliquer le concept humoristique du tag couche sale avec bonne humeur, désigner les chasseurs, surveiller les tags et encourager les réactions comiques exagérées.

🧘 Retour au calme

Tout le monde s'assoit en « position bébé » (jambes croisées). Chaque joueur imite le geste de bercer un bébé imaginaire en respirant calmement. Le groupe compte ensemble jusqu'à 10 en chuchotant.

💬 Questions de réflexion

  • Pourquoi l'humour rend-il ce jeu de tag plus amusant que les versions classiques ?
  • Comment as-tu aidé tes coéquipiers à être changés rapidement ?
  • Quelle stratégie les bébés devraient-ils utiliser pour taguer plus efficacement ?

⚠️ Erreurs fréquentes

  • Les joueurs tagués oublient de faire la démarche de canard humoristique
  • Les sauveteurs ne trouvent pas les joueurs à « changer » dans la zone de change
  • Les chasseurs ciblent toujours les mêmes joueurs
