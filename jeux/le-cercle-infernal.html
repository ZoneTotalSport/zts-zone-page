Le cercle infernal

L'équipe au centre tente de sortir du cercle formé par l'équipe adverse.

⏱️ Durée : 10-15 minutes

🎒 Matériel

  • Aucun

📐 Disposition

Équipe A forme un cercle (mains liées). Équipe B à l'intérieur.

▶️ Déroulement

  1. Ce jeu se joue à 2 équipes de 6-10 joueurs. L'équipe A forme un CERCLE en se tenant par les MAINS. L'équipe B est à L'INTÉRIEUR du cercle.
  2. OBJECTIF de l'équipe B : SORTIR du cercle (s'échapper). OBJECTIF de l'équipe A : MAINTENIR le cercle fermé et empêcher les joueurs B de sortir.
  3. Au coup de sifflet, les joueurs B essaient de BRISER le cercle pour s'échapper. Ils peuvent courir vers les bras liés, se baisser pour passer sous les bras, feinter pour trouver un point faible.
  4. Les joueurs A maintiennent le cercle en se tenant FERMEMENT les mains. Ils ajustent leur position en se déplaçant latéralement pour renforcer les points faibles.
  5. Un joueur B qui PASSE sous les bras ou BRISE la chaîne (les joueurs A lâchent les mains) est considéré comme SORTI. Il s'assoit à l'extérieur.
  6. L'enseignant CHRONOMÈTRE : combien de temps faut-il pour que TOUS les joueurs B sortent ? Le temps est noté.
  7. Puis les équipes INVERSENT les rôles. L'équipe B forme le cercle, l'équipe A est à l'intérieur. L'équipe la plus rapide à sortir (ou la plus longue à résister) gagne.
  8. Il est INTERDIT de : mordre, griffer, tirer les cheveux, frapper pour briser la chaîne, ou passer PAR-DESSUS les bras (seulement par-dessous ou en brisant la prise de main).
  9. ⚠️ SÉCURITÉ : Les joueurs A doivent LÂCHER si la pression est trop forte (risque de blessure aux poignets ou aux épaules). L'enseignant siffle si la force est excessive. Les joueurs B ne FONCENT PAS tête baissée dans le cercle.
  10. Le cercle peut se DÉPLACER (les joueurs A marchent ensemble) pour ajuster leur défense. Le cercle peut aussi RÉTRÉCIR pour renforcer les points de résistance.
  11. Durée : 10-15 minutes. Ce jeu développe la force, la coopération (maintenir le cercle), la créativité (trouver des points faibles) et la résolution de problèmes.
  12. L'enseignant encourage les joueurs B à ANALYSER le cercle : où est le point le plus faible ? Qui a la prise la moins solide ?

🔄 Variantes

  • Le cercle peut se déplacer : le cercle A peut MARCHER latéralement et même TOURNER pour désorienter les joueurs B à l'intérieur. Le mouvement rend les points faibles CHANGEANTS et empêche les joueurs B de planifier une attaque fixe.
  • Les joueurs B ont les yeux bandés : les joueurs B à l'intérieur ont les yeux BANDÉS. Ils tâtonnent pour trouver le cercle et cherchent un point faible au toucher. Un coéquipier B (le seul avec les yeux ouverts) les guide vocalement. Développe la confiance et la communication.
  • Deux cercles concentriques : l'équipe A forme DEUX cercles (un petit à l'intérieur, un grand à l'extérieur). Les joueurs B doivent briser les DEUX cercles pour s'échapper. Double résistance, double défi. Les joueurs B qui brisent le premier cercle sont dans l'espace entre les deux cercles.
  • Cercle avec portes : le cercle A a 2-3 PORTES (espaces de 1 m entre les joueurs qui ne se tiennent PAS les mains). Les joueurs B doivent trouver ces portes et les traverser AVANT que les joueurs A ne les referment. Les portes se referment quand les joueurs A se rapprochent et se prennent les mains.
