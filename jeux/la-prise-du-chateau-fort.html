La prise du château fort

Les assaillants doivent envahir le château (gros matelas) défendu par les gardiens. Les gardiens doivent repousser les assaillants.

⏱️ Durée : 20-25 minutes

🎒 Matériel

  • Gros matelas (château)
  • tapis de sol autour
  • dossards
  • sifflet
  • chronomètre

📐 Disposition

Le château (gros matelas ou zone surélevée) est au centre. 3 gardiens sur le château, 5-6 assaillants autour.

▶️ Déroulement

  1. Ce jeu se joue en 2 ÉQUIPES : 3 GARDIENS sur le château (gros matelas central ou zone surélevée de tapis empilés) et 5-6 ASSAILLANTS autour du château. Des tapis de sol sont disposés tout autour pour la sécurité.
  2. Les gardiens se placent SUR le château (debout ou à genoux) avant le début de l'assaut. Ils NE PEUVENT PAS quitter le château — leurs pieds doivent rester sur le matelas en tout temps.
  3. Au COUP DE SIFFLET, les assaillants tentent de MONTER sur le château. Un assaillant est considéré « DANS le château » lorsque son corps entier (pieds compris) est sur le matelas.
  4. Les gardiens REPOUSSENT les assaillants en les poussant avec les MAINS OUVERTES (paumes). Ils peuvent pousser les épaules, le torse ou les bras des assaillants. Il est INTERDIT de frapper, saisir les vêtements, ou pousser la tête.
  5. Les assaillants peuvent grimper, se HISSER, ROULER sur le matelas. Ils peuvent coopérer entre eux : faire la COURTE ÉCHELLE, distraire un gardien pendant qu'un autre monte, attaquer de plusieurs côtés simultanément.
  6. ⚠️ SÉCURITÉ : le château ne doit PAS être plus haut que 50 cm (2-3 tapis empilés maximum). Des tapis de RÉCEPTION entourent le château. Interdiction de TIRER les gardiens hors du château.
  7. Chaque ASSAUT dure 2 MINUTES (chronomètre). L'enseignant compte combien d'assaillants réussissent à entrer dans le château pendant ce temps. Chaque assaillant dans le château = 1 POINT.
  8. Un assaillant qui est repoussé peut RETENTER immédiatement — il n'est pas éliminé. Les gardiens doivent gérer la défense de TOUS les côtés du château simultanément.
  9. Après l'assaut, INVERSION des rôles : les assaillants deviennent gardiens et vice versa. L'équipe avec le PLUS DE POINTS d'assaillants entrés gagne.
  10. 3 ASSAUTS par équipe (pour assurer une comparaison équitable). L'enseignant peut ajuster le nombre de gardiens vs assaillants pour équilibrer le jeu.
  11. Durée totale : 20-25 minutes. L'enseignant discute des STRATÉGIES collectives : les assaillants analysent les points faibles de la défense, les gardiens planifient leur répartition.

🔄 Variantes

  • Château avec drapeau : un DRAPEAU (foulard) est planté au centre du château. Les assaillants doivent non seulement monter sur le château, mais aussi CAPTURER le drapeau et le ramener au sol. Plus stratégique.
  • Château tournant : les gardiens CHANGENT toutes les 30 secondes pendant l'assaut. Au signal, les 3 gardiens sortent et 3 assaillants les remplacent. Le rythme rapide empêche toute planification défensive.
  • Mini-châteaux : au lieu d'un gros château, 3 PETITS CHÂTEAUX (un matelas chacun) sont répartis dans le gymnase. Chaque château a 1 gardien. Les assaillants doivent conquérir les 3 châteaux. Victoire = les 3 châteaux conquis.
  • Château à niveaux : différentes ZONES du château valent des points différents : le bord = 1 point, le milieu = 2 points, le centre exact = 3 points. Les gardiens concentrent leur défense sur les zones à haut pointage.
