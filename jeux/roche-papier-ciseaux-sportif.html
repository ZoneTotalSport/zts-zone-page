Roche-papier-ciseaux sportif

Jouer à roche-papier-ciseaux (RPC) avec des défis physiques pour le perdant.

⏱️ Durée : 15 minutes

🎒 Matériel

  • Cônes
  • cerceaux (optionnel)
  • sifflet

📐 Disposition

Duos dispersés dans le gymnase.

▶️ Déroulement

  1. Ce jeu se joue en DUOS dispersés dans le GYMNASE. Les joueurs trouvent un adversaire et jouent à ROCHE-PAPIER-CISEAUX (RPC). Aucun matériel nécessaire pour la version de base.
  2. Le PERDANT de chaque RPC exécute un DÉFI PHYSIQUE annoncé par l'enseignant : 5 SQUATS, 10 JUMPING JACKS, 3 BURPEES, 5 POMPES, ou 10 sauts sur place.
  3. Le GAGNANT ATTEND que le perdant termine son défi, puis on REJOUE immédiatement. Pas de pause entre les manches — le rythme est soutenu.
  4. Après 3 DÉFAITES contre le même adversaire, le perdant doit courir un TOUR DU GYMNASE avant de reprendre. Puis on change d'adversaire.
  5. Les joueurs CHANGENT D'ADVERSAIRE après chaque série de 3 MANCHES. L'enseignant encourage les élèves à jouer avec le plus d'adversaires différents possible.
  6. L'enseignant VARIE les défis physiques à chaque RONDE (toutes les 2-3 minutes) : ronde 1 = squats, ronde 2 = pompes, ronde 3 = sauts étoile, etc. Annonce à voix forte le changement.
  7. ⚠️ SÉCURITÉ : les élèves doivent avoir suffisamment d'ESPACE pour exécuter les défis (pas de pompes dans un coin). Le gymnase doit être assez grand pour accueillir tous les duos.
  8. L'enseignant surveille la QUALITÉ D'EXÉCUTION des défis physiques : squats complets (cuisses parallèles), pompes avec le corps droit, etc. Pas de triche sur les mouvements.
  9. Ce jeu est un excellent outil de CONDITIONNEMENT PHYSIQUE déguisé en jeu. Les élèves accumulent beaucoup de répétitions sans s'en rendre compte grâce à l'aspect ludique.
  10. VARIANTE DE POINTAGE optionnelle : chaque victoire de RPC = 1 point. Le joueur avec le plus de points après 15 minutes est le champion. Ajoute une dimension compétitive.
  11. Durée totale : 15 minutes. L'enseignant peut ajuster la DIFFICULTÉ des défis selon l'âge : cycle 1 (6-8 ans) = défis faciles (5 sauts), cycle 3 (10-12 ans) = défis exigeants (burpees).

🔄 Variantes

  • RPC course : le perdant court toucher un MUR désigné et revient. Plus le mur est loin, plus le défi est grand. Version cardio-vasculaire. Simple et très efficace pour l'endurance.
  • RPC pyramide : le gagnant accumule des CERCEAUX ou des CÔNES comme trophées. Le joueur avec le plus de trophées après 10 minutes gagne. Motivation visuelle de la progression.
  • RPC train : le perdant SUIT le gagnant en file indienne (comme un wagon). Le train GRANDIT à chaque victoire du « chef de train ». Le dernier joueur libre est le champion. Très populaire.
  • RPC élimination : les perdants S'ASSOIENT sur le côté. Le dernier joueur DEBOUT est le champion. Version rapide pour éliminer et créer du suspense. Les éliminés font des exercices en attendant.
