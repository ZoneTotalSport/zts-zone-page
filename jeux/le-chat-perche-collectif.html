Le chat perché collectif

Les chats poursuivent les souris qui sont sauvées en montant sur un objet surélevé. Mais il y a un nombre limité de perchoirs.

⏱️ Durée : 10-15 minutes

🎒 Matériel

  • Bancs
  • tapis surélevés
  • marches (perchoirs)
  • dossards

📐 Disposition

Perchoirs dispersés dans le gymnase. 3-4 chats.

▶️ Déroulement

  1. Ce jeu se joue avec 20-30 joueurs dans un GYMNASE. L'enseignant désigne 3-4 CHATS (dossards). Tous les autres sont des SOURIS. Des PERCHOIRS sont dispersés dans le gymnase (bancs, marches, tapis surélevés).
  2. Les souris courent dans le gymnase. Quand un chat s'approche, une souris peut se SAUVER en montant sur un PERCHOIR (objet surélevé). Une souris perchée est INVINCIBLE.
  3. RÈGLE CLÉ : il y a MOINS de perchoirs que de souris ! (Ex : 15 souris mais seulement 8 perchoirs). Toutes les souris ne peuvent PAS être perchées en même temps.
  4. Une souris ne peut rester perchée que 5 SECONDES maximum. Après 5 secondes, elle doit DESCENDRE et courir. Un comptage est fait : l'enseignant ou les chats comptent « 1, 2, 3, 4, 5 ! DESCENDS ! »
  5. Si un chat touche une souris qui est AU SOL (pas perchée), la souris est ÉLIMINÉE et s'assoit sur le côté.
  6. Les souris doivent PARTAGER les perchoirs. Si une souris arrive sur un perchoir déjà occupé, l'ancienne souris doit DESCENDRE immédiatement. Les souris se RELAYENT sur les perchoirs.
  7. Les chats GAGNENT s'ils éliminent toutes les souris. Les souris gagnent si au moins une souris survit jusqu'à la fin du temps (3-5 minutes).
  8. Il est INTERDIT de : rester perché plus de 5 secondes, pousser une souris hors d'un perchoir, ou grimper sur des structures non désignées.
  9. ⚠️ SÉCURITÉ : Les perchoirs doivent être STABLES (bancs solidement posés, tapis sur le sol). L'enseignant vérifie chaque perchoir. Pas de saut depuis les perchoirs (descendre en marchant).
  10. L'enseignant peut RETIRER des perchoirs progressivement au fil de la manche pour augmenter la difficulté.
  11. Durée : 10-15 minutes (3-4 manches). Les chats changent à chaque manche. Ce jeu développe la course, l'esquive, la gestion des ressources limitées (perchoirs) et le partage.
  12. Ce jeu enseigne le concept de RESSOURCES LIMITÉES : il n'y a pas assez de perchoirs pour tout le monde, il faut coopérer.

🔄 Variantes

  • Retrait progressif de perchoirs : l'enseignant RETIRE un perchoir toutes les 30 secondes. Les souris ont de moins en moins de refuges. La tension monte progressivement. La dernière souris doit se débrouiller avec très peu de perchoirs. Ajoute une pression temporelle croissante.
  • Deux souris doivent être sur le même perchoir : un perchoir n'est ACTIF que s'il y a DEUX souris dessus simultanément. Une souris SEULE sur un perchoir n'est PAS protégée. Les souris doivent se coordonner pour arriver à deux sur le même perchoir. Force la coopération et la communication.
  • Les chats peuvent secouer les perchoirs (doucement) : un chat peut se placer à côté d'un perchoir et le « SECOUER » symboliquement (taper sur le banc avec la main). La souris perchée a 3 secondes pour descendre (au lieu de 5). Le chat ne peut PAS monter sur le perchoir. Rend les perchoirs moins sûrs.
  • Perchoirs musicaux : les perchoirs sont ACTIFS seulement quand la MUSIQUE joue. Quand la musique s'ARRÊTE, les perchoirs sont DÉSACTIVÉS et les souris perchées doivent descendre immédiatement. Les chats attendent les pauses musicales pour attaquer. Ajoute du rythme et du suspense.
